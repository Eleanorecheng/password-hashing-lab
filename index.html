Password Hashing Lab

同一個密碼，為什麼會有兩個雜湊？

如果兩個不同的雜湊字串都能驗證同一個密碼，程式是不是寫錯了？我們用一個測試密碼做四次雜湊，先猜結果，再用 Python 一步一步確認。

第一步｜什麼是雜湊？

雜湊函式把一段資料轉成摘要（digest）。SHA-256 的摘要固定是 256 位元，無論輸入是一個字還是一整份檔案。對同一個函式而言，相同的輸入會產生相同的摘要。密碼學雜湊也設計成很難從摘要反推出原始輸入，但如果輸入容易猜，仍然可以把猜到的值拿去雜湊，看摘要是否吻合。

第二步｜用 SHA-256 看什麼叫「相同輸入」

SHA-256 是 SHA-2 家族的通用密碼學雜湊函式，常用來檢查資料完整性。例如，下載檔案後可以計算它的摘要，再與可信來源提供的摘要比較。Python 的 hashlib.sha256() 接收位元組，所以 sha256_hash() 先用 UTF-8 編碼文字。hexdigest() 再把 256 位元的摘要表示成 64 個十六進位字元。

先猜一下：把 "hello123" 傳給 sha256_hash() 兩次，兩個摘要會一樣嗎？如果第二次改成 "hello123 "，多出來的空格算不算輸入的一部分？

看答案

第一次比較會得到 True。加上空格後，UTF-8 位元組已經變了，這兩個測試值的摘要不同。SHA-256 算得快，這對檔案完整性檢查有用，但直接用來儲存密碼會讓取得雜湊的人快速測試大量猜測。

第三步｜用 Argon2id 觀察 salt 的作用

Argon2id 是 Argon2 家族中用於密碼雜湊的變體。它用可調整的記憶體和運算成本讓每次猜測更昂貴。在這個實驗裡，argon2_hash() 每呼叫一次 PasswordHasher.hash()，函式庫就會產生一份隨機 salt。Salt 是加入雜湊運算的資料，可以和摘要存放在一起。

現在再猜一次：同一個密碼連續雜湊兩次，兩個 Argon2id 字串會相同嗎？如果兩個字串不同，verify_password() 要用哪一份 salt？

看答案

兩個字串通常不同。每個 encoded hash 都帶著自己的 salt、版本、成本參數和摘要。驗證時，函式庫從該字串讀取原本的 salt 和參數，用你這次輸入的密碼重算，再檢查摘要是否吻合。用新 salt 再呼叫一次 hash()，測到的是一次新的雜湊。

第四步｜執行程式，對照你的預測

把文末的完整程式碼存成 password_hashing_lab.py。用 Python 3.11 或更新版本，在 macOS 或 Linux 的終端執行以下指令。

python3 -m venv .venv
source .venv/bin/activate
python -m pip install "argon2-cffi>=25.1,<26"
python password_hashing_lab.py

輸入一次性測試值，例如 hello123。終端會隱藏輸入，程式只印出比較與驗證結果。

SHA-256 results equal: True
Argon2id results equal: False
Argon2id verification 1: True
Argon2id verification 2: True

前兩行比較的是字串，後兩行問的是輸入能否通過各自的驗證。把第二行的 False 和後兩行的 True 放在一起看，就能區分「兩個雜湊一不一樣」和「密碼對不對」。

加練｜故意給一個錯誤密碼

留在同一個資料夾，輸入 python 進入互動模式。先猜最後兩行會各回傳什麼，再逐行執行。

from password_hashing_lab import argon2_hash, verify_password
encoded = argon2_hash("hello123")
verify_password("hello123", encoded)
verify_password("hello124", encoded)
看答案

第一個驗證回傳 True，第二個回傳 False。如果把 encoded 換成無效的雜湊字串，程式會讓例外傳給呼叫端。這讓呼叫端能分辨密碼輸入錯誤和雜湊資料格式出錯。

完整 Python 程式碼

"""Compare general-purpose hashing and password hashing with a test password."""

import hashlib
import warnings
from getpass import GetPassWarning, getpass

from argon2 import PasswordHasher, Type
from argon2.exceptions import VerifyMismatchError

_password_hasher = PasswordHasher(type=Type.ID)


def sha256_hash(password: str) -> str:
    """Return the SHA-256 hex digest of the UTF-8 input."""
    return hashlib.sha256(password.encode("utf-8")).hexdigest()


def argon2_hash(password: str) -> str:
    """Return an encoded Argon2id hash with a fresh random salt."""
    return _password_hasher.hash(password)


def verify_password(password: str, encoded_hash: str) -> bool:
    """Return False for a password mismatch and propagate other errors."""
    try:
        return _password_hasher.verify(encoded_hash, password)
    except VerifyMismatchError:
        return False


def compare_hashes(password: str) -> None:
    """Print equality and verification results without displaying the hashes."""
    sha_hash1 = sha256_hash(password)
    sha_hash2 = sha256_hash(password)
    argon_hash1 = argon2_hash(password)
    argon_hash2 = argon2_hash(password)

    verified1 = verify_password(password, argon_hash1)
    verified2 = verify_password(password, argon_hash2)

    print(f"SHA-256 results equal: {sha_hash1 == sha_hash2}")
    print(f"Argon2id results equal: {argon_hash1 == argon_hash2}")
    print(f"Argon2id verification 1: {verified1}")
    print(f"Argon2id verification 2: {verified2}")


def main() -> int:
    """Run the experiment using a no-echo terminal prompt."""
    print("Welcome to Password Hashing Lab!")
    try:
        with warnings.catch_warnings():
            warnings.simplefilter("error", GetPassWarning)
            password = getpass("Enter a test password (never use a real password): ")
    except GetPassWarning:
        print("Hidden input is unavailable. Run the lab in an interactive terminal.")
        return 1
    except (EOFError, KeyboardInterrupt):
        print("\nExperiment cancelled.")
        return 1

    compare_hashes(password)
    print("Experiment completed.")
    return 0


if __name__ == "__main__":
    raise SystemExit(main())
